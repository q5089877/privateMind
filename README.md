# 思緒停靠 (Mind Harbor)

> 「一個安靜的自我對話空間。想說，就說一點；說不上來，也沒關係。你可以停在這裡，也可以過一會兒再回來接著說。」

思緒停靠是一個**低負擔的自我對話空間（Low-friction Self-dialogue Space）**。它不是待辦清單，也不是情緒日記或 AI 心理諮詢；它提供一個讓你可以把腦中的話說出來、安靜留下來，並在未來隨時能回來接著說的極簡容器。

---

## 🌟 核心哲學與設計原則 (Core Philosophy)

* **說出來，不強求完整**：此刻想說什麼就寫什麼；甚至只有「不知道」或「我現在說不上來」也完全足夠。
* **留下來，不強求行動**：不是每句話都需要「下一步」或「心理分析」；留下來即可結束，沒有未完成的焦慮。
* **回來看看，接著說**：跨時間重新遇見以前自己說過的話，有新的想法就繼續補上時間痕跡，不形成任務層級。
* **你可以停在任何地方**：零紅點、零推播、零完成率要求，把注意力與主導權完全還給生活。


---

## 🛠️ 技術架構 (Tech Stack)

本專案堅持「極致隱私」與「本機優先」，完全不依賴雲端伺服器與第三方 AI 模型。

* **前端介面**：HTML / CSS / JavaScript (Vanilla) / PWA
* **資料儲存**：Web LocalStorage / IndexedDB (純本機端儲存)
* **動態與無障礙**：CSS Transitions (支援 `prefers-reduced-motion`) / Web Vibration API
