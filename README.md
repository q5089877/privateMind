# 思緒停靠 (Mind Harbor) V7

> 「思緒停靠不替你整理人生。它只把腦中的東西接住，讓它先有一個地方存在；如果其中有事情要往前走，由你自己決定下一步。過去留下的痕跡不需要被否定，現在要做的事也不必被遺忘。」

思緒停靠不是 Todo App，也不是日記 App，更不是心理治療工具。它是一個讓當下腦中的內容快速離開工作記憶，並在時間中保留脈絡的個人思緒空間。

---

## 🌟 核心哲學與設計原則 (Core Philosophy)

* **入口不分類，出口可分化**：承載「念頭、感受、行動意圖」。首頁唯一入口只問「現在腦中有什麼？」。
* **啟動即輸入**：開啟 App 自動 Focus 輸入框並喚起鍵盤，零點擊阻力。
* **歷史不覆寫，現在可更新**：歷史時間線保留不同時間的自己；當前行動唯一有效置頂，指向現在。
* **行動不是 Todo**：無 Checkbox、無逾期提醒、無紅點、無完成率。
* **3 個介面動作**：`＋ 接著說……`（追加節點）、`🍃 先放這裡`（離開畫面返回首頁）、`🗑 刪除`（本機移除紀錄）。
* **零心理結論**：「已停靠」是資料被接住，「先放這裡」不代表已放下，系統絕不替使用者下結論。


---

## 🛠️ 技術架構 (Tech Stack)

本專案堅持「極致隱私」與「本機優先」，完全不依賴雲端伺服器與第三方 AI 模型。

* **前端介面**：HTML / CSS / JavaScript (Vanilla) / PWA
* **資料儲存**：Web LocalStorage / IndexedDB (純本機端儲存)
* **動態與無障礙**：CSS Transitions (支援 `prefers-reduced-motion`) / Web Vibration API
