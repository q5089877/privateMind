# 思緒停靠 (Mind Harbor)

> 「想到，就留下；想說，再回來；不必現在處理。」

思緒停靠不是待辦工具，也不是心理分析工具。它是一個讓人把「此刻腦中存在的東西」暫時放下來，並讓它隨時間留下痕跡的空間。

---

## 🌟 核心哲學與設計原則 (Core Philosophy)

* **想到，就留下**：首頁只問「現在腦中有什麼？」，不強求分類與行動，點選或寫下即可停靠。
* **時間線留下痕跡**：不是資料夾、標籤或狀態，而是以時間為唯一維度的線性軌跡。
* **不神化時間**：時間會留下變化，但產品不負責解釋，由使用者自己看見。
* **3 個物理操作**：`＋ 接著說……`（追加時間節點）、`🍃 先放這裡`（移出眼前視野）、`🗑 刪除`（永久刪除）。
* **零心理負擔**：不接管待辦、不做心理診斷、無紅點、無推播。


---

## 🛠️ 技術架構 (Tech Stack)

本專案堅持「極致隱私」與「本機優先」，完全不依賴雲端伺服器與第三方 AI 模型。

* **前端介面**：HTML / CSS / JavaScript (Vanilla) / PWA
* **資料儲存**：Web LocalStorage / IndexedDB (純本機端儲存)
* **動態與無障礙**：CSS Transitions (支援 `prefers-reduced-motion`) / Web Vibration API
