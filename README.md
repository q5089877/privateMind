# 思緒停靠 (Mind Harbor) V7.2

> **「腦中的事，不一定現在就要想清楚。」**

思緒停靠不是 Todo App、不是日記，也不是心理治療工具。它是一個讓你把**此刻腦中的東西先放下來**的極簡空間。

---

## 🌟 01～19 正式定案核心

* **入口不分類**：首頁只問「現在腦中有什麼？」，搭配四個快速輸入跨過空白，按「停靠」正式安放。
* **說不上來**：「我現在說不上來」為合法停靠狀態（「看見了。」→「先放在這裡。」），出現在歷史時間線中。
* **完成狀態**：「已安放。」即為完成，零挽留、零彈窗，可直接離開。
* **AI 入口**：有第一個文字念頭後可選「沒想法的話，換個角度看看」；單一停靠週期內最多生成 3 個近/中/遠句子起手式提示，一次性退場。AI 只讀取當前最新 Entry，不讀取歷史 Thread。
* **Thread 三明治結構**：預設僅顯示起點與終點，中間內容沉積為 `···`；點開完整展開。
* **回來看看**：去管理化時間線、無標題、無卡片框線、自然日期（如「8 月 30 日」、「今天」），不提供管理/統計工具。
* **「收起來」語言**：全面採用「收起來」、「已收起」、「放回眼前」、「讓它消失」。
* **生命週期**：永遠保留，本機儲存為原則。
* **右上角 ···**：低存在感隱形抽屜，內含「已收起」空間與「打理」（語言設定）。

---

## 🛠️ 技術架構 (Tech Stack)

* **前端框架**：React + TypeScript + Vite + Tailwind CSS + Framer Motion
* **儲存策略**：純本機端儲存 (LocalStorage / IndexedDB)，零雲端相依，極致隱私
* **提示引擎**：本機端焦距提示引擎 (近 / 中 / 遠 句子起手式) + 獨立 Safety Gate
